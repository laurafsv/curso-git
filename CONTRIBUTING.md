# Como contribuir

Este repositório também serve para praticar colaboração pelo GitHub.

## Fluxo sugerido

1. Crie uma branch com um nome descritivo.
2. Faça uma alteração pequena e objetiva.
3. Escreva uma mensagem de commit clara.
4. Abra um pull request explicando a mudança.
5. Revise o conteúdo antes de realizar o merge.

## Padrão de commits

Prefira mensagens curtas no formato `tipo: descrição`, por exemplo:

- `docs: improve README`
- `feat: add new example`
- `fix: correct page title`
