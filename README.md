# Curso de Git

Repositório criado para praticar os principais conceitos de Git e GitHub de forma simples e progressiva.

## Objetivos

- entender o fluxo de commits;
- trabalhar com branches;
- abrir e revisar pull requests;
- praticar merges com segurança.

## Conteúdo

O projeto contém uma página HTML básica usada como apoio durante os estudos.

## Como visualizar

Abra o arquivo `index.html` diretamente no navegador.
